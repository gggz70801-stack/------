详情页背景只承担氛围，不承担内容表达。所有底图会先做低饱和、压暗、轻模糊和
WebP 压缩，再进行页面遮罩；服装标识、机身编号等细节在成片中不具可读性。

素材母版放在 `media-src/bg/tactical/`，网页版由 `pnpm media:backdrops`
